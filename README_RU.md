# ZD Radial Menu

Полностью настраиваемое радиальное меню для Minecraft (Fabric). Мод добавляет
в игру круговое меню: команды, нажатия клавиш и подменю — открывается
клавишей на ваш выбор.

**Language / Язык:** Русский · [English](README.md)

## Возможности

- До 10 слотов в главном меню; у каждого слота есть имя, иконка (любой предмет
  по ID) и действие:
  - **Команда/Чат** — отправляет команду (начинающуюся с `/`) или сообщение
    в чат;
  - **Привязка клавиши** — срабатывает по выбранной привязке игры
    (инвентарь, слоты хотбара и т. д.);
  - **Подменю** — вложенный уровень со своими слотами.
- **11 видов кнопок:** Классика, Гексы, Свой, Кольцо, Пузыри, Ромбы,
  Треугольники, Сегменты, Неон, Пиксель, ГТА.
- Вид **«Свой»** — полноценный редактор раскладки:
  - перетаскивание клеток мышью (клик — выбрать, ещё клик — тащить,
    клик — отпустить);
  - точная подстройка положения по XY и размеров через кнопки;
  - настраиваемая палитра из 12 цветов плюс ручной ввод ARGB — палитра
    сохраняется в конфиг между запусками;
  - пять форм клетки: прямоугольник, гексагон, круг, ромб, треугольник;
  - хитбоксы повторяют форму клетки с запасом в 3 пикселя — по нарисованным
    кнопкам легко попадать;
  - добавление/удаление клеток и сброс раскладки к значениям по умолчанию.
- Вид **«Сегменты»** — кольцевое меню: при входе в подменю оно разворачивается
  во внешнее кольцо, а родительский уровень остаётся внутренним
  (клик по нему — назад).
- Три режима показа подменю: поверх, кольцом, отдельно.
- Все кнопки интерфейса редактора в одном стиле: полупрозрачная тёмная заливка
  с белой обводкой.
- Существует редактор для создания пользовательской формы.
- Конфиг сохраняется автоматически при закрытии любого экрана редактора.
- Полная локализация: английский и русский (следует языку игры).

## Установка

1. Установите [Fabric Loader](https://fabricmc.net/use/installer/) для вашей
   версии Minecraft.
2. Положите в папку `mods`:
   - [Fabric API](https://modrinth.com/mod/fabric-api) под вашу версию игры;
   - `zdradialmenu-<версия>.jar` со
     [страницы релизов](https://github.com/ZxcDaisuke21/ZD-RadialMenu/releases).

## Использование

- Откройте меню клавишей, назначенной в **Настройки → Управление**
  (категория мода).
- **Левый клик** по сегменту — выполнить его действие.
- **Правый клик** по сегменту — открыть настройку этого слота.
- Кнопка **«Настройки»** в правом нижнем углу меню открывает полный
  редактор меню.
- В редакторе кликните по слоту, чтобы настроить его; кнопками **−/+**
  меняйте число слотов, кнопкой **«Вид кнопок»** переключайте внешний вид.
