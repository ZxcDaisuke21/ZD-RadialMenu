# ZD Radial Menu

Мод всё ещё находится в стадии разработки! Некоторые из перечисленных ниже функций еще не реализованы!

Радиальное меню команд и действий для Minecraft на Fabric. Открывается по настраиваемой клавише, всё настраивается прямо в игре — без правки конфига вручную (хотя конфиг — обычный JSON, при желании его можно править и блокнотом).

**Language / Язык:** Русский · [English](README.md)

## Возможности

- **До 10 слотов** в главном меню; у каждого слота — название, иконка (любой предмет по id) и действие:
  - **Команда/чат** — отправляет команду (начинается с `/`) или сообщение в чат;
  - **Клавиша** — нажимает выбранную игровую привязку (инвентарь, слоты хотбара и т. д.);
  - **Подменю** — вложенный уровень со своими слотами.
- **Восемь видов кнопок**: Классика, Гексы, Свой, Кольцо, Пузыри, Ромбы, Треугольники, Сегменты.
- **Вид «Свой»** — полноценный редактор раскладки:
  - перетаскивание ячеек мышью;
  - точная подстройка положения X/Y и размера через поля ввода;
  - палитра из 12 цветов плюс ручной ввод ARGB;
  - пять форм ячеек: квадрат, гексагон, круг, ромб, треугольник;
  - добавление и удаление ячеек, сброс раскладки.
- **Вид «Сегменты»** — кольцевое меню: при входе в подменю оно раскрывается внешним кольцом, а родительский уровень остаётся внутренним (клик по нему возвращает назад).
- Все кнопки интерфейса в одном стиле: полупрозрачная тёмная заливка с белой обводкой.
- Конфиг сохраняется автоматически при закрытии экранов редактора.

## Установка

1. Установите [Fabric Loader](https://fabricmc.net/use/installer/) для вашей версии Minecraft.
2. Положите в папку `mods`:
   - [Fabric API](https://modrinth.com/mod/fabric-api) под вашу версию игры;
   - `zdradialmenu-<версия>.jar` со [страницы релизов]([<Релизов еще нет>](https://github.com/ZxcDaisuke21/ZD-RadialMenu/releases/tag/v1.0.5-1.21.11f)).

## Использование

- Откройте меню клавишей, назначенной в **Настройки → Управление** (категория мода).
- **Левый клик** по сегменту — выполнить действие.
- **Правый клик** по сегменту — открыть редактор этого слота.
- Кнопка **«Настройки»** в правом нижнем углу меню открывает полный редактор меню.
- В редакторе: клик по слоту — настроить его, кнопки «−/＋» — изменить число слотов, кнопка «Вид кнопок» — переключить внешний вид.

## Конфиг

Файл: `config/zdradialmenu.json`. Пример:

```json
{
  "skin": "DONUT",
  "sectorCount": 4,
  "sectors": [
    {
      "name": "День",
      "command": "/time set day",
      "icon": "minecraft:clock",
      "type": "command",
      "keyBinding": "",
      "children": []
    },
    {
      "name": "Стройка",
      "command": "",
      "icon": "minecraft:brick_block",
      "type": "submenu",
      "keyBinding": "",
      "children": [
        {
          "name": "Креатив",
          "command": "/gamemode creative",
          "icon": "",
          "type": "command",
          "keyBinding": "",
          "children": []
        }
      ]
    }
  ],
  "customLayout": [
    { "dx": 0, "dy": -40, "w": 56, "h": 48, "color": 0x60808080, "shape": "hex" }
  ]
}
